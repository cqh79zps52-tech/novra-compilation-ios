# Machine de compilation jetable

Ce dépôt ne contient **aucun code produit**. Il ne porte qu'un fichier de
compilation, qui va chercher le code d'un dépôt privé avec une clé de
déploiement en lecture seule.

Il existe parce que les machines macOS de GitHub sont gratuites et illimitées
sur un dépôt public, alors qu'un dépôt privé dépend d'un budget mensuel.

Rien ne s'y déclenche tout seul : la compilation demande le droit d'écriture
sur le dépôt. Il se supprime une fois le binaire récupéré.
